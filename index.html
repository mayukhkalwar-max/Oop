C++17 Console Prototype

Offline / Online Exam System v3

A fault-tolerant, thread-safe exam engine featuring atomic file writes, keystream obfuscation, real-time heartbeats, and simulated cloud sync.

View Repository Build & Run

Key System Features

Thread-Safe Execution

Background watchdog thread using steady clock countdown, ensuring accurate time keeping immune to system clock tampering.

Data Integrity

Atomic file operations via temp file renaming and fail-safe file quarantine upon detected damage or tampering.

Multi-Role Access

Role-based management (Master, Admin, Student) with dynamic one-time authentication passcodes.

Offline / Online Sync

Automatic state detection saving progress locally while syncing securely to simulated servers when connected.

Compilation & Running

Compile using a POSIX-compliant C++17 compiler (GCC or Clang):

g++ -std=c++17 -O2 -pthread exam_system.cpp -o exam
./exam

File Infrastructure

File Role & Description
admin.dat Key salt generated automatically for obfuscation key derivation.
students.txt Registered student database and state records.
questions.txt Question bank editable through administrative privilege.
config.txt Exam global parameters (duration limit in minutes).
answers_<id>.* Encrypted local response store per student session.
lock_<id>.txt Heartbeat locking mechanism protecting against multi-login.
